# Manage Tasks - Vue.js

A modern, responsive task management application built with Vue.js. Create, edit, delete, and organize your tasks with an intuitive interface. Tasks are persisted in local storage, so your data stays safe even after closing the browser.

## 🚀 Live Demo

[View on GitHub Pages](https://mohammeddev1.github.io/manage-tasks-vuejs)

## 📦 Tech Stack

- **Vue 3** - Progressive JavaScript framework
- **Vue Router** - Official router for Vue.js
- **Vuex** - State management library
- **Vite** - Next generation frontend build tool
- **Tailwind CSS** - Utility-first CSS framework
- **ESLint & Prettier** - Code quality and formatting tools

## ✨ Features

- ✅ **Create Tasks** - Add new tasks with title, description, and status
- ✏️ **Edit Tasks** - Update existing tasks with ease
- 🗑️ **Delete Tasks** - Remove tasks with confirmation modal
- 🔍 **Search & Filter** - Quickly find tasks by title
- 📊 **Task Status Management** - Track tasks with three statuses:
  - Not Started
  - In Progress
  - Completed
- 💾 **Local Storage** - Tasks are automatically saved to browser's local storage
- 📱 **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- 🔔 **Alert Notifications** - Get feedback for all task operations
- 📈 **Task Statistics** - View counts for all, completed, in-progress, and not-started tasks
